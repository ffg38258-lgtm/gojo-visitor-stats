مشروع صورة غوجو وإحصائيات الزيارات

المتطلبات:
- Node.js 18 أو أحدث
- استضافة تدعم Node.js

التشغيل محلياً:
1) فك ضغط الملف.
2) افتح الطرفية داخل مجلد المشروع.
3) نفّذ: npm install
4) عيّن كلمة مرور لوحة الإحصائيات:
   Linux/macOS: export ADMIN_PASSWORD='كلمة-مرور-قوية'
   Windows PowerShell: $env:ADMIN_PASSWORD='كلمة-مرور-قوية'
5) شغّل: npm start
6) افتح: http://localhost:3000

الرابط العام:
ارفع المشروع إلى استضافة تدعم Node.js (مثل Render أو Railway أو VPS)، واضبط:
- Start Command: npm start
- Environment Variable: ADMIN_PASSWORD = كلمة مرور قوية
بعد النشر، رابط الصفحة هو رابط الاستضافة، ولوحة الإحصائيات:
https://رابط-موقعك/dashboard

الخصوصية:
الصفحة تعرض إشعاراً وتطلب موافقة قبل إرسال حدث الزيارة.
تُسجّل المدينة والدولة التقريبية والوقت ونوع الجهاز والمتصفح فقط.
لا يُخزّن عنوان IP الخام ولا تُجمع إحداثيات GPS أو عنوان المنزل.
تحديد المدينة من IP تقريبي وقد يفشل أو يعرض مدينة مزود الإنترنت.
